API Key

This extension uses OpenRouter to access uncensored AI models. OpenRouter is free to sign up and offers free uncensored models (no credit card required for free-tier models).

How to get your free API key
  1. Go to openrouter.ai and create a free account.
  2. Navigate to Keys in your dashboard.
  3. Click Create Key and copy it.
  4. Paste it below. The default model is free — no billing needed.

Your key is stored locally in Chrome sync storage and never sent anywhere except directly to the OpenRouter API.

SpicyChat — RPG Session Tracker

Adds a persistent side panel on SpicyChat.AI chat pages with a full RPG session tracker: Quest Log, Dice Roller, Resources, Abilities, Party, NPCs, and Rumours. All data is saved per chat and persists across page loads. Events are auto-inserted into the chat input as formatted [bracket] lines.

Enable RPG tracker panel Only active on spicychat.ai/chat/* pages. Reload the tab after changing.

Formatter

The formatter cleans up text and wraps anything outside quotation marks in asterisks — no AI, instant, no API calls. Trigger it with the keyboard shortcuts below.

Enable formatter Allows the formatter keyboard shortcuts and auto-format to run
Auto-format after rewrite Automatically runs the formatter on every AI rewrite result (requires formatter to be enabled)
NORMALISATION
Strip existing asterisks Remove all * before re-applying formatting, for a clean result
Normalise curly quotes → "..." Convert “ and ” to straight double quotes
Normalise curly apostrophes → ' Convert ‘ and ’ to straight apostrophes
Normalise ellipsis ... → … Convert three dots to the proper ellipsis character
Collapse multiple spaces Replace two or more consecutive spaces with one
Capitalise standalone i → I Corrects the pronoun i and contractions like i'd, i'm, i'll to use a capital I
Capitalise first letter inside "quotes" e.g. "oh wow" → "Oh wow" — treats quoted speech as dialogue
Em-dash -- → — Convert double-hyphen to a proper em-dash — she paused -- then spoke → she paused — then spoke
Remove space before punctuation e.g. hello , world → hello, world  ·  she said . → she said.
Ensure space after punctuation e.g. hello.she → hello. She  ·  wait,then → wait, then (skips decimals like 3.14)
Trim paragraph whitespace Remove leading and trailing spaces from each line
Normalise paragraph spacing Ensure every paragraph is separated by exactly one blank line
Capitalise sentences Capitalise the first letter of each paragraph and after . ! ?
WRAPPING
Preserve lists Leave bullet lists (- item) and numbered lists (1. item) unwrapped in asterisks. Also prevents paragraph-spacing from inserting blank lines between consecutive list items
Leave [ ] square brackets unwrapped Text inside [brackets] is kept bare, not wrapped in asterisks
ROLEPLAY
Repair unclosed action markers * If a line has an odd number of asterisks, close the dangling one at the end
Action punctuation *waves* → *waves.* Ensure actions wrapped in asterisks end with a sentence-ending punctuation mark. Actions ending with . ! ? , : … or — are left untouched; others get a . appended
Clean up OOC double-brackets (( )) → ( ) Convert ((out of character)) double-bracket notation to single parentheses

Characters to leave unwrapped, as pairs. E.g. () to leave (parentheses) bare. Multiple pairs: (){}.

Ctrl +

Click the field and press any letter or number key. Formats the focused text input and, on SpicyChat, prepends the RPG tracker summary. Default: Ctrl+M.

Ctrl + Shift +

Runs the formatter on the focused input but never prepends the RPG tracker summary. Default: Ctrl+Shift+M.
